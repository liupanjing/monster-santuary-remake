# 逐角色制作与审核

每次只推进一个角色。当前是主角奥尼克，ID 51。

主角有两套独立精灵设计：战斗版按原版身体比例重绘；跑图版按原版 npc0 的 Q 版比例重绘。用户确认前不制作动作，也不把战斗图直接缩小作为跑图图。

1. 展示原版精灵并说明来源。正背图、动作图、剪影和推测设定分别标明。
2. 对照确认轮廓、头身比、配色、脸部、服装/器官/装备及战斗姿态；把无法确认的部分单独列出。
3. 画一个角色的新版造型，提交原版与新版的并排对照；说明哪些细节保留、哪些细节属于补充。
4. 记录用户的修改意见，逐版修订。用户认可造型后，才制作多方向、行走/战斗动作和图集。
5. 在 Unity 实际野外尺寸与战斗尺寸下检查可读性、锚点、透明边缘和动作；需要的修正仍回到该角色记录。
6. 用户明确认可该版后记录 `approvedVersion` 和确认依据，替换正式资源并提交 Git，再处理下一个角色。

审核清单位于 `Art/character-review.json`，每个角色独立目录为 `Art/Reviews/<ID>/`。默认顺序为主角、土系 1–9 阶、异翅巨蟒，再处理剩余怪兽；用户可随时调整顺序。

状态含义：

|状态|含义|
|---|---|
|`pending_original_review`|尚未确认原版识别特征|
|`draft_review`|单角色新版草图待用户审核|
|`revision_requested`|用户要求修改|
|`design_approved`|用户已认可造型，动作和导入尚待完成|
|`runtime_review`|动作与 Unity 中的实际效果待确认|
|`approved`|用户认可的资源版本已记录并导入|
|`rejected_v1_placeholder`|旧资源仅供运行占位，未通过审核|

当前主角为 `draft_review`（v4 双枪模块化稿待确认），其余角色为 `pending_original_review`；土之秘境中的运行资源仍为 `rejected_v1_placeholder`。独立武器预览场景可以检查图层与挂点；自动验证不代替用户认可造型。
