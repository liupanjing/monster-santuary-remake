# 逐角色制作与审核

角色各自建档和确认。主角奥尼克 ID 51 的 v4 造型已认可，v5 动作待评价；八宝 v2 造型已认可、v3 动作已接入。用户最新要求全部角色继续按同一方法制作，本批扩展为全角色静态候选，保留每个角色独立素材与对照；批量制作不自动授予认可。

主角有两套独立精灵设计：战斗版按原版身体比例重绘；跑图版按原版 npc0 的 Q 版比例重绘。用户确认前不制作动作，也不把战斗图直接缩小作为跑图图。

1. 展示原版精灵并说明来源。正背图、动作图、剪影和推测设定分别标明。
2. 对照确认轮廓、头身比、配色、脸部、服装/器官/装备及战斗姿态；把无法确认的部分单独列出。
3. 画每个角色的新版造型，保存其独立的原版与新版并排对照；说明哪些细节保留、哪些细节属于补充。用户本轮已授权按清单批量推进静态稿。
4. 记录用户的修改意见，逐版修订。用户认可造型后，才制作多方向、行走/战斗动作和图集。
5. 在 Unity 实际野外尺寸与战斗尺寸下检查可读性、锚点、透明边缘和动作；需要的修正仍回到该角色记录。
6. 用户明确认可该版后记录 `approvedVersion` 和确认依据，再制作动作与替换正式资源；静态候选可以先单独提交 Git。

审核清单位于 `Art/character-review.json`，每个角色独立目录为 `Art/Reviews/<ID>/`。默认顺序为主角、土系 1–9 阶、异翅巨蟒，再处理剩余怪兽；用户可随时调整顺序。

八宝为固定随行灵兽，单独建档于 `Art/Companions/babao/`，记录在审核清单的 `companions` 中，不改变原版 50 只可收服怪兽编号。用户指出 v1 各视角翅膀不一致，随后明确认可 v2 统一双翼造型并授权动作接入；v3 已按此制作四向悬浮/扇翅/固定跟随，新动作视觉评价另行记录。

当前西雅记录在独立 `npcs` 清单、七贝在 `companions` 中，详见 [西雅审核](../Art/NPCs/xiya/REVIEW.md)与[七贝审核](../Art/Companions/qibei/REVIEW.md)。v1 为静态候选，不授予造型认可或代表原剧情事件已恢复。

状态含义：

|状态|含义|
|---|---|
|`pending_original_review`|尚未确认原版识别特征|
|`draft_review`|单角色新版草图待用户审核|
|`revision_requested`|用户要求修改|
|`design_approved`|用户已认可造型，动作和导入尚待完成|
|`runtime_review`|动作与 Unity 中的实际效果待确认|
|`approved`|用户认可的资源版本已记录并导入|
|`rejected_v1_placeholder`|旧资源仅供运行占位，未通过审核|

主角 v4 造型已被用户认可，v5 动作处于 `runtime_review`，已接入土之秘境；其余怪兽运行中仍使用未通过的 v1 占位。全角色静态稿统一为 `draft_review`，不自动替换运行素材。主角档案区分已认可造型与待验收新动作，不把技术通过等同于动作视觉通过。

全角色画册与任务清单位于 `Art/AllCharacters/2026-10-13/`：50 只怪兽、27 套剩余 NPC 造型或变体、4 张独立剧情头像，另有异翅巨蟒独立跑图版，共 82 项素材任务。头像与跑图可能属于同一剧情身份，因此不称为 82 个独立剧情角色；NPC 共用造型时保留原版资源身份，不凭外观猜名字。主角、八宝、西雅、七贝沿用各自已有独立档案。
