# 怪兽仙境 Remake 2D：土之秘境可玩版

目标：Unity 2D、原版俯视迷宫与回合战斗风格、主角和全部怪兽重新绘制；先完成土之秘境的探索与驯兽师考试。

## 运行

直接打开 `Build/MonsterWonderland2D.app`。本次提供 Mac 桌面包；Windows 包尚未构建或验证。

源码工程：同级目录 `MonsterSanctuaryRemake2D`，Unity 6000.3.0f1。打开 `Assets/Remake/Scenes/Earth2D.unity`，点击 Play。地图、角色和界面由数据在运行时加载。

- WASD / 方向键：移动；Shift：快走。
- E：交谈、开宝箱、进入洞口、调查入口传送石。
- Space / Enter：继续对话。
- M：当前区域地图；Esc：队伍与行囊；F5：保存。
- 战斗：先决定奥尼克的行动，再决定出战怪兽的行动。点击敌人的名字选择目标。快捷键 1/2/3 对应攻击、治疗或技能、防御。
- 削弱敌人后使用封印球收服。在队伍界面选择出战怪兽；怪兽数量超过一页时可翻页。
- 入口传送石可休整和购买补给。取得秘境碎片后，走回入口调查传送石，完成第一阶段考试。

正常存档位于 Unity `Application.persistentDataPath/earth-2d-v2.json`。自动测试使用独立输出目录。重新开始会先备份当前记录。

## 本版内容

- 主角奥尼克 + 50只怪兽，共51个全新二维角色形象。五系1～9阶和5只特殊种均已绘制并导入。
- 主角四向，每向3张独立行走图；按8Hz以“迈步－中立－另一脚－中立”播放。怪兽当前使用一张基础精灵配合位移、闪烁表现动作，尚无各自完整逐帧攻击动画。
- 三层土之秘境，27个原包区域、69个出口记录、上下层碰撞和楼梯切换。
- 28个原位置宝箱/箱子。22个物品奖励能从 `2001.bin` 恢复，其中21个在当前普通路线的交互范围内可达；6个未找到对应奖励，暂展示为空箱，不编造原版物品。77:8的大宝箱保留原位置，但当前普通路线不可达，待进一步核对原版进入条件。
- 怪兽遭遇种类、区域和等级范围来源于原包 `mmp/*.bin`；角色成长采用 `m.java` 的整数公式，极低数值保底1。
- 主角 + 一只出战怪兽，对阵最多三只敌人；攻击、治疗、技能、防御、血瓶、收服、撤退、经验与升级。
- 原版五系克制：风→雷→土→水→火→风，正向伤害125%，逆向75%，无属性不受影响，来源 `w.java`。
- 守护者使用原脚本里的8号怪兽“异翅巨蟒”。胜利获得171号“秘境碎片”，返回入口交付，完成考试。关键台词来自原脚本，入口交付是本章试玩的流程适配。
- 50只怪兽的图鉴、队伍分页、行囊、魔瓶补魔、补给、存档、少量复古提示音。

## 素材来源与新绘范围

`art-source` 保存内置 imagegen 生成的原图与提示词；`sprite-manifest.json` 记录源图、角色ID、透明通道、切片与比例。所有主角和怪兽图片是新绘图像，经连通区域切片、统一最近邻缩放和固定脚底支点导入。

原图保留不变；透明像素中的背景RGB不会显示。游戏精灵使用二值alpha，清除半透明底色边缘和相邻角色串图。

地形、宝箱、少数人类NPC与战斗背景沿用已解析原包素材；全部怪兽与主角使用新图。工程未包含FBX或三维角色资源。

## 可审查的地图适配

地图45当前解析出来的碰撞与可见地形不能直接构成完整通关路线。本版保留原始JSON于 `OriginalEvidence`，另导出 `map45-compatibility-overlay.json`，只为原碰撞中阻塞的可见地面增加通行覆盖，同时保留原有可通行的暗路。没有覆盖原始JAR或原资源文件。这不是“原版碰撞已完全还原”的声明。

门口的原像素触发矩形转换为格子触发区域，楼梯矩形按格子接触范围转换，角色采用四向格子移动和插值位移；这些是二维重制适配。

完整路径检查覆盖上下层状态和门口连接，当前358条向前步骤、360条返回步骤。实际程序重放同样的移动、楼梯和转场逻辑。

## 范围与后续

这是土之秘境可通关的开发版。没有把全部剧情、所有技能、状态异常、性格/亲和度、合成、仓库和联网章节宣布为完成。

首次进入使用10级奥尼克与10级豆猪、100金币和少量补给，是本章试玩起点，不代表原版开场配置。守护者暂以10级和伤害倍率0.65进行试玩平衡；原脚本的25级与多项5000参数尚未全部解码。

普通伤害、治疗、收服概率、遭遇节奏及经验/金币奖励仍是可玩子集的平衡规则，尚未逐条等同原版。原版已确认的成长、克制、怪物种类、宝箱奖励与地形连接另有来源记录。

部分NPC支线和缺失联网速度测试脚本尚未移植。音乐待补，当前只有提示音。50只怪兽的基础画面已经齐全，独立动作帧与最终画风打磨继续分批完成。
