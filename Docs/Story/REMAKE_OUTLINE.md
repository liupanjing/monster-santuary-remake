# 怪兽仙境 Remake · 扩写剧情大纲

版本：v1，2026-10-13。性质：供讨论与后续制作使用的完整故事提案，尚未接入游戏，未定稿新增角色造型。前期承接 [原版梳理](ORIGINAL_STORY.md)；后期与新增答案明确属于 `remake_expansion`，不是恢复了缺失原作结局。

## 1. 故事方向

保留原作轻松、爱斗嘴、带人情味的冒险气质，让故事随着少年认识世界而逐渐深入。开头的愿望是“通过考试，成为传奇”；经历几次代价后，奥尼克开始理解怎样对伙伴、帮助过自己的人和自己的选择负责。

主线的一句话：**一个想成为传奇的少年，在考试途中卷入封印危机，最终与伙伴找出一条让各地都能继续生活的道路。**

三条叙事线共同推进：

1. 奥尼克的成长与考试：从依靠祖父名声和逞强，走向整备、求助、合作与独立决断。
2. 西雅的旧案：四年前的伏击、里奥克斯的遭遇和血爪的行动，逐步改变她的追索方式。
3. 耐法瑞的旧选择与封印危机：四十年前的冒险留下的问题，在新一轮喷涌中重新出现。

八宝贯穿三条线。怪兽通过救人、护路、探路与共同战斗参与情节，让养成与探索实际影响冒险。

## 2. 扩写采用的世界规则

以下规则为新编机制，最终定稿时要与原文和玩法参数分开记录：

- 暗能量喷涌会使部分怪兽、环境与旧机关失衡，解释高阶怪兽出现在村边等异常；并非所有野生怪兽都是受污染的敌人。
- 古代封印体系除地表封堵，还包含深层缓冲与调节通路。长期失修使封口只能延缓危机，打开别处封印成了各方争夺的捷径。
- 五系秘境分别保留一部分调节体系与守护知识。修复需要人类技术、当地资料和怪兽不同能力协作，不能只收集五件物品后自动解决。
- 重制中的旧案与四十年危机有关联，但四年前的受害者、证人和具体责任需要逐人查明，不能凭一个大陆的出身判断所有人。
- 情缘水晶保留原传说与情感意义。扩写中可以帮助面对痛苦，使用由人物自己决定；不把它做成自动清除一切感情的万能答案。

源质矿石、奥尼克身世与里奥克斯命运不在此版强行补成同一“血脉谜底”。有证据的关系先写清，新增答案只在确实服务人物时采用。

主角已认可的双枪造型继续使用。原早期西尔多任务奖励弹弓的事实保留在原剧情档案；重制可以把当前持枪起点下的西尔多事件改成元素融合教学，弹弓作为该任务的独立装备奖励，其各自姿势与功能单独制作。这是装备流程适配提案，不回溯改变原奖励。

## 4. 关键人物的扩写弧线

### 奥尼克与八宝

前期让奥尼克持续吹牛，八宝持续拆台；每次真正危险出现时，都给他们一次互相理解的行动。奥尼克在取回皮皮时看到怪兽已有的羁绊，在厚土龙蛭前接受救助，在雷章学会准备与合作，在水章理解他人的处境，终局为一条艰难但有依据的共同方案承担责任。

八宝的可靠逐步显现：会害怕、会抱怨，也会在照明、寻路、报信和紧急返回中留到最后。终局让八宝与七贝承担一条独立支援路线，主角的战斗无法代替这项工作。所有能力都有取得条件与边界，不能随时解决所有机关。

### 西雅、七贝与克莱尔

西雅的旧案通过证言、物件和她自己的叙述逐步呈现，避免一次长对白说完。原土章保护西雅受伤的事件保留，但后续要写她与奥尼克怎样吸取教训；两人并肩行动时分工明确，不反复让主角受伤推进她的情绪。

七贝知道同行者疲惫，也会把关心转成行动。克莱尔关注团队与平民代价，与西雅发生有依据的争执；两者都在行动中承担责任。案件终点必须回答里奥克斯遭遇与血爪的责任，原设定的未确认与重制采用的新答案分别记录。

奥尼克与里奥克斯相似的原线索保留；本提案优先把它用于西雅面对旧伤和认清当下的情节，不预设奥尼克是转世、克隆或血亲。

### 耐法瑞与家乡

四十年前的故事分三次出现：开场是夸张的寻宝故事；中期记录暴露遗漏；归乡时他承认当年方案的局限。新增旧事让他的保护与隐瞒都有后果，但保留原版的幽默、经验和关爱。

小依拥有照顾奶奶、处理村中事务与帮助罗丽的生活目标，主角通过家信和返乡得知这些变化。西尔多与六奶奶也参与家乡的准备和灾后工作。已有村庄建筑与设施因此成为玩家熟悉的生活场所。

### 丽丝、考官与普通冒险者

丽丝的往事独立于里奥克斯旧案。情缘水晶支线可涉及记忆、祭念和再次出发，由丽丝自己选择如何纪念；考官的等待也需要有边界和自己的生活。罗伯斯与瓦莎可通过后续家信和一次重逢，展现一条不追求传奇称号的冒险者成长线。

诺滋与多姆继续提供喜剧，也在一次区域疏散中把滑板能力用在实处。普通人、灵兽与低阶怪兽都能对解决危机有所贡献。

## 5. 反派与终局提案

新增幕后组织暂称“断封派”，名字与造型待定。其目标是在新一轮喷涌前优先保护自己控制的地区，认为把灾害导向别处比等待所有人合作更现实。组织可以招募不同背景的人，不以大陆或族群决定善恶。

血爪保留前期破坏者身份，其实际参与程度、动机与四年前责任在案件线中查明；有苦衷也不能抹掉造成的伤害。幕后首领使用明确的新角色，不自动将1009的神秘人设为最终反派。

最终冲突围绕两种已能执行的方案展开：强行打开放弃地区的封印，或冒险恢复经过各章验证的深层缓冲体系。玩家先在五系地区帮助过的人和怪兽能够提供维护、材料、工艺、路线和守护经验，才使后一方案具有可信度。此前章节必须展示小规模修复的成功与限制，避免终局突然出现万能办法。

最终战依然以主角与一只出战怪兽的既定结构进行，其他人物通过剧情支援与场景行动发挥作用；本大纲不自行改为多角色常驻队伍战斗。

结局完成本次危机的止损、旧案责任与主要人物线的回收。封印得到维护而非永远不存在风险；主角通过考试是旅程的一部分，传奇称号由经历与人物评价自然产生。首版采用一个完整主结局，支线影响后日谈与人物近况，分支结局另行设计。

## 6. 伏笔与待定事项

为让这版故事有完整回收，先提出以下新增答案作为 v1 推荐方案，可随后续资料或讨论修订：里奥克斯是西雅曾深爱的同队搭档，四年前为保护撤离队伍与井口封印而死；血爪参与伏击，后续证据明确其个人责任。奥尼克与里奥克斯的相似没有预设血缘或转世解释，西雅最终能够看见奥尼克自身的选择。这些具体关系和生死均属于重制新增设定，不能填回原版档案当作已核实事实。

耐法瑞的四十年前冒险在 v1 中采用“守住当时的井口，却未能修复整个古代调节体系”的答案；拜访他的神秘人推荐设为当年同行者，带来新一轮异常的消息，与3073技能传授者保持两个身份。幸运符优先作为祖父送给少年的家乡纪念，在返乡谈话中回收，能力与来源同样标记为新编。吟游诗人与小依的相似可保留为独立短支线，首版主线无需以她们的隐秘血缘才能成立。
