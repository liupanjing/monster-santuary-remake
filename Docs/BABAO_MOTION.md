# 八宝动作与游戏接入

用户已认可 v2 统一双翼造型；本次授权制作四方向悬浮、扇翅和跟随，切换参战怪兽不能更换八宝。详见 [v3 制作与验证](../Art/Companions/babao/v3/README.md)。

`BabaoMotionLibrary2D` 管理四向帧、循环、悬浮幅度与跟随间距；`BabaoFollower2D` 管理路径、自身朝向、层级、翅膀采样及独立影子；`ChapterBabao` 将同伴 Prefab 接入探索层并提供独立参战怪兽选择接口。它们不查询怪兽目录来决定八宝外形。

`EarthGame2D` 不再创建随队伍选择而变化的野外怪兽 Sprite。主角移动仍使用已有 Q 版组件；八宝在 LateUpdate 沿历史路径前进，待机、菜单和对话中继续轻微悬浮。战斗隐藏探索层，参战精灵继续由选中怪兽决定；战斗结算不再覆盖野外同伴图片。

八宝无战斗单位、成长数值或新增存档槽位。没有改动主角双枪模块或原版怪兽 ID。完整游戏规划文档由另一批工作维护，本次仅记录当前同伴实现与验证范围。
