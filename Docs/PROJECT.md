# 项目立项

项目：怪兽仙境 Remake。立项日期：2026-10-13。

## 目标

在独立 Git 仓库中维护电脑端 Unity 2D 重制。第一阶段以土之秘境可玩章节为范围，同时重新制作主角与全部怪兽的 2D 精灵。迷宫仍采用原版俯视布局和上下层通行，战斗保持主角带一只出战怪兽的回合结构。

## 当前纠正

上一版一次生成整套角色，加入了大量原图没有的造型细节，用户指出整体偏离原画。现撤销其定稿地位：51 个角色全部回到待原版审阅，旧图仅保留为原型占位和比较资料。

重绘以原版可识别特征为依据。像素原图不足以确认的细节不擅自当作事实。仅有剪影的特殊种需要单独设计和确认。
