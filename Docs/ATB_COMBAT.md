# 行动条战斗 · 重写 v1

2026-10-14：用户明确要求废弃旧战斗系统，并选择“行动条制：速度推动行动条，角色到点后下达指令”。旧 `ChapterCombat`、回合指令数组和 `ResolveRound` 已删除。当前 Unity 章节使用新规则层，不保留旧结算作为运行 fallback。

本版本仍用主角＋一只出战怪兽、最多三敌验证。八宝仍为独立随行同伴。参战人数是本次接入规模，不是规则层的硬编码限制。沿用已核实的角色成长与五系关系，技能、伤害、收服和 Boss 数值均明确属于重制设计，不宣称恢复95条原技能或37条原效果。

## 时间与指令

- 战斗初始行动条为0，就绪阈值100。每秒增长 `12 + 2.4 × sqrt(speed)`。速度提高行动频率，不再每回合重排一次顺序。
- 推进精确停在最近的就绪边界。同一时刻就绪时，以参战名单稳定顺序处理：主角、怪兽、敌方登记顺序。
- 我方就绪后暂停所有行动条，单独选择该角色的指令与目标；敌方就绪后执行其决策。结算演出期间时间也暂停。没有旧的双人回合确认。
- 攻击/治疗等单体指令必须选择合法目标；防御等自身技能、群体技能直接确认。目标使用遭遇内独立ID，多个同种怪兽不会混淆。移除、死亡后旧目标无效，不暗中改打另一只。
- 行动完成后行动条回到 `-recovery`。普通攻击、防御为0；瞄准射击为-25，Boss暴走为-35。因此高威力技能付出额外准备时间。
- 冷却单位是施法者自己的行动：冷却1需完成一次其他行动后才能再次使用。MP、冷却、物品、目标、Boss限制全部通过后才消耗。
- 当前是等待型行动条制，选指令不限现实时间；不是边选菜单边受攻击的即时模式。

## 技能与角色职责

配置位于 `Resources/Data/atb-combat.json`，所有技能使用 `remake:` ID，共34条定义（包括五种血瓶、五种封印球、通用指令和Boss技能）。这不等于34条原版技能恢复。

|角色/元素|首版战术|
|---|---|
|奥尼克|攻击、瞄准射击、迟缓压制、指定队友急救、血瓶、收服、撤退、防御|
|风|风刃打击迟缓目标追加伤害；顺风提高队友行动条速度|
|雷|施加破绽提高受伤；群体电网有概率眩晕|
|土|单体突岩、指定队友岩甲、群体震地|
|水|单体水箭、指定队友治疗、群体寒潮迟缓|
|火|先引燃施加灼烧，再焚爆消耗灼烧追加伤害|
|无|自我强化、物理猛击|

原50只怪兽目前按元素分配重制职责，不宣称已有逐只专属技能、学习条件或独立动作。后续可以在配置中增加物种覆盖；本次未替换待审核美术，也未制作未授权角色动作。

## 伤害、防护与状态

物理伤害：`(基础威力 + 攻击 × 系数 + 连招追加) × 100 / (100 + 防御)`。

魔法伤害使用魔攻与 `100 / (100 + 0.65 × 防御)`，因此同样受到防御影响；首版没有另立魔防属性。随后应用输出强化、五系克制、破绽和防御，整数取最近值，伤害至少1，再由护盾吸收，剩余扣HP。五系沿用风→雷→土→水→火→风，125%/75%，无系不参与克制。

|效果|规则|
|---|---|
|防御|受到伤害减半，至自身下次就绪；不跨战斗保存|
|护盾|先吸收伤害；重复施放取较高护盾值，不累加；战斗结束清除|
|迟缓/加速|行动条速度×0.65/×1.35，持续按受影响者自己的行动计数|
|破绽/强化|受伤/输出×1.25；相同状态刷新剩余次数，不无限叠加|
|灼烧/中毒|在受影响者就绪时扣固定HP，绕过护盾；死亡后不再下令|
|眩晕|就绪时消耗一次行动机会，行动条重新开始；Boss最多受控一次就绪|
|沉默|受影响行动期间不能使用耗MP技能；该次行动完成后再移除到期状态|

状态开始作用、持续伤害和冷却都在明确的就绪边界处理，到期状态在行动结束移除。没有隐含的全局“回合结束”。不支持复活、反弹、多段技能等尚未实现规则；添加时需扩充效果与对应验证。

## 敌人与守护者

普通敌人交替普攻与可用专长；水系会优先治疗低于半血的队友。攻击目标按行动次数在存活我方之间轮换，支援目标按生命比例选择。敌方面板展示下一次技能与目标；受到控制、目标死亡、冷却或进入阶段后会重新计算。

守护者拥有翼爪、毒翼袭击、横扫风翼。半血以下才可使用狂风暴走，造成全体伤害与迟缓，并承担更长恢复时间。阶段技能不会进入高血量时的通用技能选择。技能参数为新配置，已删除旧全局Boss伤害×0.65规则。

封印球逐级独立选择、消耗；收服概率由血量平方项与球/怪兽阶层比组成，范围5%～95%。Boss禁止收服与撤退。收服直接移除该敌方身份，加入队伍一次。主角倒下即败，怪兽倒下后主角可以继续。胜负和奖励提交只有一个出口；保留章节金币/经验、失败回入口、碎片与任务交付，以验证探索衔接。
