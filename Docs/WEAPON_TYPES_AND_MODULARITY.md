# 四种特殊武器的类型与模块化安排

|武器|能确认的类型|确认依据|外形与玩法边界|
|---|---|---|---|
|弹弓|弹弓 / 弹射武器|名称明确为弹弓，说明为打玻璃的利器|原表没有提供射程或专属弹药类型|
|法师之眼|魔力驱动的远程武器|用魔力驱动的远程武器|魔力驱动不等于已确认攻击消耗 MP 或使用魔法伤害公式|
|残酷之弩|弩 / 弩类远程武器|名称中的弩；说明只确认魔兽大赛奖励与稀有性|弩箭种类、装填与射程没有从原说明恢复|
|驯兽者之鞭|鞭 / 鞭类柔性武器|名称中的鞭；说明确认属于驯兽师的极品武器|不能由驯兽者名称推定提高收服率或控制怪兽的隐藏效果|

法师之眼的准确外形没有从本地包恢复；只确认“魔力驱动的远程武器”，不能定成魔导枪、法杖或眼球。四类握持方案属于重制设计，不应表述为原版已恢复的专属动作。

## 可替换资源

- 角色身体精灵不包含武器。战斗版与跑图 Q 版分别设计。
- 每种武器有独立 WeaponDefinition2D，含原物品 ID、类别、适用握持姿势、各视角精灵、精灵缩放与枪口/发射口。
- 角色 HeroPoseDefinition2D 含身体、左右手握点、握持角度、遮挡层；弩、弹弓、鞭使用对应姿势，不能强行套双枪握拳。
- HeroEquipmentRig2D 换枪只换武器层；不重绘身体。不存在的姿势或未画的武器会拒绝替换，不产生残缺换装。
- 当前双枪预览使用一张中性短枪精灵的两手实例；它不是任何原版武器的定稿。11 种武器只建立独立数据资源，型号图片尚待逐件制作。
- 原版仅有一个武器装备槽；双枪是该槽的双手视觉呈现，没有增加第二份装备数值。
- 长枪、弩等双手武器应以一个武器实例配支撑手姿势，不自动复制成双枪；鞭身变形、弩弦、弹弓拉放及魔法特效以后由各自资源驱动。
- 本轮只做静态造型与组件验证，尚未开发武器动作、弹药/MP 规则、弹道和伤害换算。
