# 主角动作接入

当前角色造型基线为用户认可的 v4。动作版本为 v5，已经接入 Unity 2D 土之秘境试玩，视觉验收仍待用户评价。

[动作资源、实际播放 GIF 与验证说明](../Art/Reviews/51/v5/README.md)

跑图与战斗使用两套独立资源：跑图保持 Q 版四方向待机、行走与奔跑；战斗保持认可身体比例，提供呼吸待机、双枪射击/后坐力、受击、防御与胜利。枪械通过每帧握点独立挂载。

每种枪以原版物品 ID 对应独立 WeaponDefinition2D。当前默认双枪图已认可，七种原版枪的型号图仍未制作；11 种原版武器的数据蓝图保留，不能把默认手枪当作这些型号的恢复结果。

射击的两个枪口事件共享一次攻击结算，保留原型伤害数值。角色动画不控制装备数值：按装备替换外形的接口与后续完整装备玩法分开，存档只增加视觉装备 ID。
