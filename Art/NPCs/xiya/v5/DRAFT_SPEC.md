# 西雅高清造型与连续挥剑草稿

范围：一个大比例战斗造型、一条单手斜斩的连续铅笔草稿；未做 Q 版新动作、Unity 替换或装备量产。

身份依据：原包 hpic4 与 npc_xiya；原版配色为紫发、绿色主衣/头饰、金胸扣、粉腰带、深色内层与绿靴。轻型银护具、团服结构、武装带与剑鞘是用户指定方向下的新设计。

动作依据：前轮实际观看的任天堂《御天之剑 HD》剑击短片用于研究身体与剑路衔接；不复制林克造型或声称复原特定游戏动画。GDQuest / Clembod 参考动作可读性与攻守转换。

动作草稿：固定三分之四前视，人体右手持剑，人体左髋空剑鞘。戒备 → 紧凑引剑与转肩 → 切过目标 → 延续减速 → 恢复戒备。整体为单次攻击，不在出剑过程中突然改成第二套攻击。

制作方法：统一造型后，在同一图卷中绘制一组连续动作草稿；每格是同一身体同一视角的相邻时间点，包含过渡姿态。只做技术裁切与公共画布注册，不从旧战斗立绘选图拼接，不用光流补间、交叉淡入淡出或特效遮断层。不按每帧人体包围盒分别放大。

视觉检查：肩肘腕与剑尖路径，持握侧别、剑长度、护手/拇指结构，躯干扭转与双脚承重，头与服装体积，末段回戒备。检查关键帧和实际播放；技术切片成功不能自动标为自然。

全部是待用户审核的草稿。高清造型未认可前，不扩充其他方向/角色或改正式游戏资源。
