# 主角武器证据

原版物品表的武器类别为 0；运行物品槽为 0–206。下面为本地完整记录的 11 种武器。

|ID|名称|原版说明|
|---|---|---|
|0|弹弓|打玻璃的利器，具备微弱的攻击力|
|1|火绳枪|点燃火绳后才能发射，威力也不大|
|2|轮燧枪|使用方便，威力凑合，但容易走火|
|3|来复枪|射速不高，但威力比较令人满意|
|4|战斗短枪|方便携带的短枪，威力也很不错|
|5|弹子短枪|战斗短枪的改进版，提升了威力|
|6|伯恩特步枪|部队的制式武器，威力和稳定性一流|
|7|麻雀短枪|画了一只小麻雀，不知意味着什么|
|8|法师之眼|用魔力驱动的远程武器|
|9|残酷之弩|魔兽大赛的奖励品，稀有之物|
|10|驯兽者之鞭|属于驯兽师的极品武器|

ID 11–30 为需要外部数据的占位，本地没有名称；不能补写猜测。末尾 ID 207 彩票记录不在 207 个运行物品槽的合法下标范围内，不列为主角武器。

用户明确纠正主角使用枪。原版主角战斗图按角色 ID 加载，而不是按装备名称加载，因此无法仅凭物品名把立绘中的枪指定为某一种型号。重绘先遵循原图的持枪位置和尺寸；具体枪身细节属于待确认补绘。

v2 将枪误画为刀，已撤回。当前候选 v3 为持枪修正版；战斗与跑图仍使用独立比例，尚未制作动作或替换 Unity 资源。
