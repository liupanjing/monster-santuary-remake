# 八宝 v3 · 四方向悬浮、扇翅与独立跟随

用户已明确认可 v2 统一双翼造型，并要求制作四方向动作、接到主角身后、切换参战怪兽时保持八宝。本版沿用 v2 造型；新动作的视觉评价单独记录。

## 动作与资源

- 正面、左侧、背面各 4 张扇翅关键图；右侧根据左右对称结构镜像左侧。共 12 张独立新绘图、16 张运行 PNG，明确区分镜像与独立新画。
- 按 `0→1→2→3→2→1` 往返循环。待机每秒采样 8 次，跟随 12 次，奔跑跟随再提高 15%；这是图帧采样节奏，不是整个游戏 FPS。
- 身体保持稳定，抬翼/下压由新绘帧表达。悬浮是程序控制的约 ±0.045 格起伏；影子单独停留在地面。身体尺寸与锚点从轮廓下缘登记，各图集共用缩放，禁止按每帧全轮廓撑满。
- 侧面远翼跟着近翼下压，部分阶段受身体遮挡，只露翼尖。三个视角沿用同一对青蓝双瓣翅膀，未回退到 v1 无翼侧块。

源图由内置 imagegen 生成/编辑，[提示词](prompts/)原样保存，切片代码只做透明分帧、尺寸登记及右向镜像。[制作记录](motion-manifest.json)记录来源、哈希、裁切和尺度。正面源图后两张抬翼阶段时序不合适，未用于循环；没有声称六张都是正确循环关键图。

Unity 资源在 `Resources/BabaoMotion/`，配置为 `Animations.asset`，可复用对象为 `Prefabs/BabaoFollower.prefab`。角色不依赖出战怪兽 ID；队伍切换只更改 `activePet`，战斗仍显示所选出战怪兽。

## 跟随规则

八宝沿主角经过的折线路径保持约 1.45 格距离（实拍后拉开，防止正面被主角头部挡住），转向由自己当前走过的路径决定。方向变化时不把它直接拉到主角身边的斜线位置；楼层跟随路径记录切换。换地图、失败回入口和重载时重新建立本地图路径，进入战斗时隐藏整个跑图层，退出后恢复。出生点后方不可通行时，优先选侧面或前方可通行的相邻格；四周均无空间时才从主角所在格建立跟随，避免放进墙里。

不新增八宝存档字段，因此现有 v2/v3 存档保持兼容。回城、滑板变形、召唤商店和照明能力属于后续功能，本次不因原版特殊帧而宣称已实现。
