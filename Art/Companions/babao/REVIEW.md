# 八宝 · 固定随行灵兽

状态：用户于 2026-10-13 要求补八宝，随后指出 v1“部分视角有翅膀，部分没有，统一做成有翅膀的吧”。v2 已修订为各视角统一双翼的静态候选；未获造型认可，未制作新版动作，未接入 Unity 正式试玩。v1 保留为需修订版本，不作动作基线。

## 原版依据

- `Reference/OriginalGame/dialogue.txt` 的 `[1010.bin]`：八宝说“就这么带着豆猪就上了？”；奥尼克称它为灵兽。这说明八宝与出战豆猪为不同角色。
- `Reference/OriginalGame/decompiled/e.java` 260–274：演员 0 为主角，演员 1 通过 `b.a(a, 4)` 跟随；使用滑板时停止跟随并隐藏。场景 9、65、75 的演员 0/1 分别为 `npc0` / `cw`，可用 `Tools/inspect_original.py` 从原始场景重新解析验证。
- `cw.png` + `cw.bin`：按 `y.java` 的矩形、部件镜像、动画索引合成。恢复 23 张原版帧、10 段索引序列；这些是恢复的原版资料，不是新画的动画。记录见 [解码数据](v1/original-decoding.json)。
- 原版 `d.java` 默认四方向动画为 0–3；cw 的序列对应背面、正面、左、右。新候选只画静态正面、左侧与背面，未把镜像当成第四张新图。
- `items.json` 索引 200/201/202：回城魔杖、滑板魔杖、召唤魔杖借助八宝。洞穴照明见 `dialogue.txt` 关于“这样的洞子我还勉强可以照亮”的对话。这些为原版能力证据，不代表本次已实现。
- 同包的 `cw2` 为相同布局的洋红色版本。用途未证实；本次不据此改变八宝常态配色。

## v1 造型

[原版 / 新版对照](v1/babao-original-vs-redraw.png)。保留浅青蓝圆身、深蓝边缘和小翅膀、头顶卷曲突起、横向眯眼、粉红脸颊及小红嘴；不增添衣服或武器。侧面翅膀的分瓣和背部卷曲折线，是低像素原图的重绘解释，需用户评价。

原版棕色下方区域按地面阴影处理，新版人物 PNG 不含阴影。同框尺寸依据原版 cw 正面 15 像素（含影）/ npc0 正面 23 像素作粗略展示；它不是已经通过游戏镜头验证的最终尺寸。

内置 imagegen 生成初稿后，修正过大的双层卷曲突起，减少高光。源图、两份原样提示词、透明切片和生成/切片记录均在 [v1](v1/)。代码仅做参考提取、切片和排版，没有替代绘画。

## v2 统一双翼修订

[最新原版 / 新版对照](v2/babao-original-vs-redraw.png)。按用户明确要求统一为一对青蓝色双瓣小翅膀：正面两翼向斜上外侧伸出，背面显示同一对翅膀和根部；侧面近翼展开，远翼因身体遮挡只露翼尖。翅膀统一位于身体上半部两侧，不再以椭圆侧块代替。圆身、眯眼、粉颊、红嘴、头顶单个卷曲突起和配色延续 v1。

这项改动属于用户要求的造型修订，不宣称原版所有视角本就画出了同样大小的翅膀。原版资料保持不变；v2 由内置 imagegen 编辑 v1 透明源图，保存 [原样提示词](v2/prompts/wings.txt)、源图、三张静态透明切片及生成记录。人工检查三视图都有可辨认的翅膀、边缘未裁切、图格不串入；尚无动作或运行验证。
